# 量子计算学习与科普站 · 开发方案 v1.0

> 对标：小山学堂 `xueai.miyang.cn`（原 `xueai.app`）
> 结论：**静态优先 + 单节一交互 + 内容闸门**，6 周出 MVP（24 节可学），12 周出 V1（≈124 节 + 自测中心），年度成本 < ¥100。

---

## 0. 一页结论

| 项目 | 决定 |
|---|---|
| 形态 | 门户首页 + 侧边栏阅读器 + 独立单节课页（MPA，非 SPA） |
| 技术栈 | Astro 6（最新稳定版）+ MDX + TypeScript + Pagefind 搜索；交互用原生 TS 岛，复杂组件用 Svelte |

| 自测 | `exam.html` + `exam-data-*.js` | 七套篇章卷 350 题，模拟考 + 顺序刷题双模式 |
| SEO | 每页 `<script type="application/ld+json">` | `Article + LearningResource`，含 `hasPart.cssSelector=".paywall-locked"` 标注付费部分、canonical、5 语 hreflang、每节独立 OG 图 `og/<slug>.jpg` |

**它的设计令牌**（直接沿用精神，换成量子气质的配色）：

```
浅色：--bg #f7f5f0  --card #fff  --text #1c1c1e  --sub #6b7280  --accent #146b54
深色：--bg #101512  --card #171d19  --text #e9ece9  --accent #5cb595
--radius 14px  --radius-sm 10px  --content-w 1200px  --shadow-card 0 1px 3px rgba(0,0,0,.04)
```

**可以照抄的四个决定**（是它体验好的真正原因）：
1. **数据与页面分离**：加一节只改 `course-data`，门户、侧栏、上下页、搜索全部自动生效。
2. **一节 = 一条主张 + 一个可播放的演示 + 一句结论**：400–600 字，不做长文。
3. **演示进视口才播、可重播**：`lessonOnView(el, fn)` + `↺ 重播`，不靠用户点"开始"。
4. **SEO 按页手工注入**：标题、描述、canonical、OG 图、结构化数据一个不落，静态站也能吃满收录。

**不照抄的地方**：它用 466 个手写 HTML（维护成本高、无类型校验、跨页重复 head）；我们用 MDX + 内容集合 + 构建期校验，同样的体验，错误在 CI 就拦掉。

## 2. 定位与差异化

面向四类人，一条主线四条支线（对标它的 routes 机制）：

| 路线 | 人群 | 学到哪 |
|---|---|---|
| 只想搞懂 | 好奇者、文科生 | 第 1 篇 + 第 3 篇直觉部分，看得懂新闻 |
| 考试/竞赛 | 本科生、考研、物理竞赛 | 1–5 篇全学，会算、会读线路图 |
| 动手做 | 开发者、研究生 | 1–5 篇 + 实验室自由搭线路 + 真机跑 |
| 判断力 | 投资人、产品、媒体 | 1、6、7 篇 + 祛魅篇，能识别夸大宣传 |

**四个差异化（决定别人为什么来你这而不是看维基）**

1. **每个概念都能"跑"**：布洛赫球、振幅条、线路实验室、Grover 竞速、QFT 相位轮、BB84 窃听游戏——浏览器里零安装，结果可复制成 QASM 上真机。
2. **祛魅，不吹**：专设一篇"量子计算常见误区 20 条"，明确写清量子优势的适用条件、NISQ 阶段真实进度、哪些"量子+"是营销。科普站最缺的是**敢说没用的地方**。
3. **中文语境**：衔接国内教材符号（`|0⟩` 在 +z、`σ_x` 与 `X` 的记法差异）、国产平台（本源量子云等）、考研与竞赛常见问法。
4. **数学最小必要**：独立一篇"只用得上的数学"，复数/内积/酉矩阵/张量积各一节，每节配可视化，不做线性代数全书。

## 4. 单节课模板（页面规范）

每节都是同一条流水线，不临场发挥：

```
① 面包屑 / 篇章徽章 / 预计 6 分钟 / 标签（概念·交互·反例·深入）
② 大论断 .big-claim         ≤ 40 字，整节只服务这一句
③ 引导段 2–4 句             承接上文，给出本节要回答的问题
④ 交互演示（本章核心）      自动播放 + 重播 + 参数滑块 + 结果数值
⑤ 拆解段 2–3 段 × 100–150 字  每段一个小标题，段末一句加粗结论
⑥ 常见误解卡片（反例）      ❌ 常见说法 / ✅ 准确说法 / 差在哪里
⑦ 一句话结论 .conclusion-card
⑧ 3 道即时检查（单选 + 解析）
⑨ 出处脚注（教材章节 / arXiv / 官方文档）
⑩ 上一节 / 下一节 + "这节哪里不清楚？"反馈（GitHub Issue 预填）
```

**写作规则（写进 CONTENT_GUIDE.md，AI 与人都按这个写）**
- 正文 400–700 字（不含公式、代码、题目）。
- 一个概念只用一次比喻，且必须声明比喻在哪里失效。
- 术语首次出现必须 `<Term id="superposition">叠加</Term>` 包裹，自动链到术语表。
- 不写"众所周知""显然""大家都知道"。
- 不用"量子"作形容词修饰非量子事物（量子水、量子鞋垫类表述直接禁词拦截）。
- 所有数值给单位和条件（保真度 99.9% 要写清是 1-qubit 随机基准测试）。
- 主张与出处绑定：涉及进展/纪录的句子必须带来源。

## 5. 交互引擎与演示组件

### 5.1 `qsim` 引擎（约 700 行 TS，零依赖，先写它）

```ts
const c = new Circuit(2)
c.h(0).cnot(0, 1)

c.state()                 // 复振幅 Float64Array（实部/虚部交错）
c.probabilities()         // [0.5, 0, 0, 0.5]
c.bloch(0)                // { x: 0.0, y: 0.0, z: ~0 }（纠缠态单比特完全混合）
c.expectation('ZZ')       // 1
c.sample(1024, { seed: 7 })   // { '00': 509, '11': 515 }
c.toQASM()                // OpenQASM 2.0 文本
c.snapshot()              // 逐步历史，供"单步执行"回放
```

- 门集：`I X Y Z H S S† T T† Rx Ry Rz CNOT CZ SWAP Toffoli CP`，以及受控任意单比特门 `cU(control, target, matrix)`。
- 复杂度：单比特门 O(2ⁿ)，n ≤ 10 同步计算；11–14 放 Web Worker；n ≥ 15 拒绝并提示。
- 正确性：用 Qiskit 生成一组基准线路的期望结果（JSON fixture），CI 里逐条比对振幅与概率（容差 1e-9）。**这是整个站最容易被写错、也最需要测试的部分。**
- 可视化薄层：`amplitudes()` 直接喂图表组件，`blochOf(qubit)` 喂布洛赫球。

## 6. 技术选型与目录结构

**为什么是 Astro**：默认零 JS 输出（内容站最需要的）、MDX 写课、岛屿架构让 11 个交互组件各自独立加载、静态构建产物可直接扔 CDN、`astro:content` + zod 天然替代 `course-data.js` 并带类型校验。相比 Next 少一层运行时，相比纯手写 HTML 多一层工程保障。

├─ package.json
├─ src/

│  ├─ content/lessons/

### 内容 schema（`src/content.config.ts`）

```ts
const lessons = defineCollection({
  loader: glob({ pattern: '**/*.mdx', base: './src/content/lessons' }),
  schema: z.object({
    title: z.string().max(30),
    slug: z.string().regex(/^\d{2}-\d{2}-[a-z0-9-]+$/),
    part: z.enum(['p-start','p-intuition','p-math','p-qubit','p-entangle','p-algo','p-hw','p-app']),
    topic: z.string(),
    tag: z.enum(['概念','交互','动画','反例','深入','实战']),
    minutes: z.number().min(3).max(20),
    thesis: z.string().max(40),          // 大论断，强制填
    demos: z.array(z.string()).min(1),   // 至少一个演示
    quiz: z.array(z.object({
      q: z.string(), options: z.array(z.string()).length(4),
      answer: z.number().min(0).max(3), explain: z.string().min(20),
    })).min(2),
    sources: z.array(z.string()).min(1), // 至少一条出处
    draft: z.boolean().default(false),
  }),
})
```

- 标签沿用它的"药丸"语法：概念=黄、交互=绿、反例=红、深入=橙、实战=蓝。

## 8. 内容生产流水线与质量闸门

```text
选题表(大纲) → AI 起草(thesis 先行) → 配演示/图 → 3 道题 → 出处
   → check-content.mjs 拦错 → 物理/数学审校清单 → PR 预览 → 合并自动部署
```

`check-content.mjs` 的硬规则（不过就 CI 红）：

| 检查 | 阈值 |
|---|---|
| 正文字数 | 350–900 字 |
| thesis 长度 | ≤ 40 字，且不得与 title 重复 |
| 演示引用 | `demos` 非空且组件真实存在 |
| 题目 | ≥ 2 题，每题 4 选项 + 解析 ≥ 20 字 |
| 出处 | ≥ 1 条，且形如 `作者, 年份, 标题/章节` |
| 术语 | 首次出现的术语必须被 `<Term>` 包裹或已在 glossary |
| 禁词 | 众所周知 / 显然 / 毋庸置疑 / 量子水 / 包治 / 秒杀经典计算机 |
| 数值断言 | 出现 %、倍、qubit 数、年份的句子必须带来源 |
| 公式 | 必须能通过 KaTeX 渲染，且 `<Formula>` 带 `label` |
| 链接 | 站内链接不得 404（构建后扫描 dist） |
| 页面元数据 | title ≤ 60 字、description 80–160 字、canonical、OG 图存在 |

**物理学审校清单（每篇一份，逐条打勾）**
1. 符号约定统一：`|0⟩` 取 +z 本征态；`X/σ_x` 混用需在首现处声明。
2. 概率归一：每个演示的直方图总和为 1，面板显示实际数值。
3. 测量假设写清：投影测量、坍缩后状态、多次 shots 的统计解释。
4. 门矩阵正确：与 Nielsen & Chuang 或 Qiskit 文档一致，全局相位不影响可观测结果需注明。
5. 复杂度表达准确：Grover 是 √N 次**查询**，不是"快平方倍"泛泛而谈。
6. 优势表述有边界：写清问题类型、输入规模、与最优经典算法的对比、以及是否已被经典算法追平。
7. 不制造玄学：纠缠不传递信息；不可克隆不等于不可复制近似。
8. 时间敏感内容加"截至 2026-xx"标注。
