制备一个<Term id="bell-state">Bell 态</Term>，测一万次，理想直方图只有 00 与 11。实际会看到一小撮 01 和 10。门都做对了，错在最后那一下「看一眼」。

## 读出是另一本账

读出一个超导比特，通常借旁边的谐振腔：比特状态不同，腔的共振频率移动不同，反射微波的相位也就不同。把相位判成 0 或 1 需要阈值，阈值两侧有重叠，于是有把 0 判成 1、把 1 判成 0 的概率。读出<Term id="fidelity">保真度</Term>就是把这两个误判概率折算出来的一个数，常报到 99% 量级。

它和门错误分开记账：门错是态被算错，读出错误是态对、标签错。Bell 态冒出 01，最典型的原因就是其中一个比特的标签翻了。

## 速度、复用与污染

读出要时间：积分越久，信噪比越好，误判越少；但读出期间比特可能弛豫，其他比特在等。分辨时间指刚好能分开 0 与 1 所需的最短积分时间。

多比特系统用复用读取：每个比特配一个频率不同的腔，一根线同时送多个频率，一次读出整排比特。省时间，代价是频率拥挤、串扰与带宽限制；读得越快，越容易把邻居的信号混进来。

读出错误污染结果，最直接的是误码率：量子密钥分发（QKD）里的量子比特误码率（QBER）包含读出错误，校准没做好会把安全阈值算错。算法里，读出错误会让能量估计、采样分布整体偏移，看起来像算法错了。

缓解有两类。校准矩阵：先用已知的 0 与 1 态测出混淆矩阵，再对测量结果求逆；噪声大时求逆会放大涨落，要用最小二乘或贝叶斯。重复读出：把一次读出拆成几段、分段判决再取多数，能压住部分偶然误判；前提是读出近似量子非破坏（QND），而且会花时间。两种办法都只是「估计得更准」，没有降低物理错误率。

<Conclusion>
  读出不是「看一眼」那么无辜：阈值判决会把 0 判成 1，Bell 态里的 01 就是这么来的。它和门错误分开记账，会污染误码率与算法结果。校准矩阵与重复读出让估计更准，但没有降低物理错误率。
</Conclusion>
