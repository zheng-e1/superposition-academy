量子力学不得不用复数吗？把每个振幅记成「一个大小加一个角度」，两个实数，听起来也够用。可一旦要算两条路径合起来的结果，这套记法就开始漏气——毛病出在乘法上。

## 复数：缩放加旋转

$i^2 = -1$ 不是一条要背的规则，它描述一个几何动作：乘 i 把平面上的箭头逆时针转 90°，转两次就转到反方向，所以 $i^2$ 就是 −1。

复数 $z = a + bi$ 有两部分，模和辐角。加法是分量相加，很平常；乘法才是重点，它同时做两件事——模相乘，辐角相加。共轭 $\bar z = a - bi$ 把角度取反，于是 $z\bar z = |z|^2$，除法也能写成乘法：$1/z = \bar z/|z|^2$。

欧拉公式把这件事写成一个符号：$e^{i\theta} = \cos\theta + i\sin\theta$。它是单位圆上的点，角度就是辐角；两个这样的数相乘，等于角度相加。门里的相位因子都是它的特例：S 门给 $\left|1\right\rangle$ 加的是 $e^{i\pi/2}$，Z 门加的是 $e^{i\pi}$。

## 为什么不用两个实数

假设硬用「模 + 角度」两个实数。加法勉强能定义，乘法就得额外补一条规则：结果的角度是两个角度相加再对 $2\pi$ 取模。麻烦还不止于此——角度从 $2\pi$ 跳回 0 的地方不连续，任何依赖连续性的线性运算在这里都会出错。而量子力学的演化必须是线性的：$U(\alpha\psi + \beta\varphi) = \alpha U\psi + \beta U\varphi$。

干涉项更直接。两条路径的振幅相加，概率是

$$
P = \left|a+b\right|^2 = \left|a\right|^2 + \left|b\right|^2 + 2\operatorname{Re}\left(a\bar b\right)
$$

最后那一项可正可负，条纹全靠它。用两个实数硬拼，这一项得自己补进去；用复数，它是乘法结构自动给出的副产品。

算一遍，两个振幅的模都是 1。相位差 0 时 $a = b = 1$，$P = 4$，全增强；相位差 π 时 $a = 1$、$b = -1$，$P = 0$，全相消；相位差 90° 时 $a = 1$、$b = i$，$P = 2$，正好等于两个概率相加，交叉项为零。同一个「模」，三种结局。

所以复数不是记账的记号。它是让加法与相位能互相作用的那层结构——<Term id="interference">干涉</Term>之所以能发生，是因为振幅之间可以相乘、角度可以相加。

<Conclusion>
  复数在量子力学里不是装饰。它把「大小」和「方向」放进同一个乘法，于是两条路径的振幅相加时会自然多出一个交叉项。干涉不是复数的产物，但没有复数，你得把干涉一项一项手工补回去。
</Conclusion>
