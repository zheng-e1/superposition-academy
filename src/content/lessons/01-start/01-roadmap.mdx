同一个站，有人只想知道新闻里那句「量子优势」算不算数，有人三月要交一份量子算法的课程作业，还有人想自己写线路、发到真机上跑一次。三种人打开同一份目录，需要的顺序完全不同。所以第一件事不是学什么，而是先认领一个目标：**学量子不是一条路，是四条。**

## 四条路线，各自停在不同的地方

**只想搞懂**，约 2 周。零基础就能走，不需要线性代数，只需要愿意在偏振片上拖几下。读「开始之前 → 量子直觉 → 单量子比特」，停在单量子比特的末尾。走完你应该能判断一篇报道在哪一句开始夸大，也能说清测量到底做了什么。

**考试与竞赛**，约 8 周。要一点高中复数，以及愿意动笔的耐心。这条最长：「开始之前 → 量子直觉 → 数学最小必要 → 单量子比特 → 多比特与纠缠 → 线路与算法」。复数、酉矩阵、张量积都得手算一遍，只看不算等于没学。硬件与应用两篇可以整篇跳过。

**动手做**，约 6 周。会一点 Python 就够，数学篇的大部分推导可以先略过，但线路要真跑：「开始之前 → 单量子比特 → 多比特与纠缠 → 线路与算法 → 量子实验室」。到实验室那篇，你得能自己搭一个 Bell 态、导出 QASM、在真机上看到采样结果，并解释它为什么不是 100%。

**要判断力**，约 4 周。给记者、投资人、要给项目签字的人。读「开始之前 → 量子直觉 → 硬件与工程 → 应用与生态」，数学篇整篇略过也行，但硬件那篇的五条路线、相干时间与保真度、<Term id="threshold">纠错阈值</Term>一个都不能跳——判断力就长在这些指标上。

## 路线是默认值，不是判决

四条路线共用同一个开头，「开始之前」谁都要读，之后才分叉。站内的 /roadmap 就是按这个分法裁剪目录：选中一条，它只展开这条路要读的篇目，其余收起来。

<Callout title="换路线不必从头再来" tone="phase">
  缺哪一篇就补哪一篇，已经读过的不会作废。真正浪费时间的不是换路，是在一条不合适的顺序里硬耗耐心。
</Callout>

<Conclusion>
  路线只回答两个问题：现在读哪一篇，读到哪停。它不评价你学得快不快，也不承诺读完能达到什么水平。选错了就换一条——换的成本，远低于在错误的顺序里耗掉的耐心。
</Conclusion>
